Goals

Import a lesson

⏱ About 4 minutes🔁 Once per lessonYou need: the lesson's TEKS Alignment CSV
Why: your lesson project makes a TEKS Alignment file for each lesson. Import it once, and on the period page you can pick an activity instead of typing the Activity and TEKS. Its codes raise goal alerts exactly as if you'd typed them. Don't have a lesson project yet? See Set up the Leveled Guide BuilderNEWfor version 0.4.18 and beyond; it makes this file. Already using leveled guides? See Leveled guides: set upNEWfor version 0.4.18 and beyond.
1

Settings → Lesson activities → Import lesson CSV…

Pick the lesson's … - TEKS Alignment.csv. A preview shows each activity (brackets removed from the names) and its codes in your short form (113.41(d)(28)(A) becomes 28A).

A Look for column?NEWfor version 0.4.21 and beyond A file from a newer builder prompt has a sixth column, Look for. The preview shows each one in grey under its code, and so does the lesson's list under Imported lessons. It tells you where to check that TEKS in the activity, and it shows on the goal alerts that activity raises. A file without the column imports exactly as before.

2

Choose its unit, tick the periods that teach it, then Import

Put in unitNEWfor version 0.4.22 and beyond starts on the unit of the lesson you imported last; change it if this lesson belongs elsewhere (see Organize lessons into units). Under Show this lesson on, tick at least one period. You can tick more later under Imported lessons.

3

On the period page: Lesson activity…, then a unit

Click Lesson activity….NEWfor version 0.4.22 and beyond It opens on Pick a unit: the units with a lesson for this period, newest first, and No unit last.

4

Pick the lesson

The line under the title shows where you are; click Units in it, or Back, to go back. Each topic is a small grey heading, with Learn It, Comprehend It, then Apply It.

5

Click each activity you want, then Done

Each activity shows the codes it fills in. Click one and it's added right away; the pop-up stays open and marks it ✓ Added, so you can click more, or go Back to another lesson.NEWfor version 0.4.22 and beyond Click Done when you're finished.

6

The boxes fill in; check them and Save

Each activity is added to the Activity boxes (after a ;) and its codes to the TEKS box. Nothing is saved until you click Save.

✓ You'll know it worked

  • Imported "The New Deal - Learn It": 3 activities, 13 codes. In Unit 5 — The New Deal. Shows on P2.
  • Picking fills the Activity and TEKS boxes.

✕ Avoid these

  • No period ticked. Import is refused until one is.
  • Expecting it to replace what you typed. It adds after a ;.
  • Clicking Cancel or Done to undo a pick. They only close the pop-up; delete the text from the box instead.

⚠ If you see this

Not imported: "…" has 2 problems. Nothing was saved.Each problem is listed by line number. Fix the file and import again.No lessons for Period … yet.Tick that period for a lesson in Settings → Lesson activities.
