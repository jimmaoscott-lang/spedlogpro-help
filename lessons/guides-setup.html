Lessons & leveled guides

Leveled guides

⏱ About 4 minutes to set up, 3 per guide day🔁 Once per lesson; each day you hand out guidesYou need: the lesson's TEKS Alignment and Guide Supports files, in one folder
Why: your Leveled Guide Builder also writes a Guide Supports file: which supports (word bank, sentence stems, chunking…) it built into each level of the guide. Import it with the lesson, and on a guide day the app shows which of each student's accommodations that guide covers.
Part 1

Set up (once per lesson)

1

Keep both files from the builder in one folder

No builder yet? See Set up the Leveled Guide Builder. The builder makes … - TEKS Alignment.csv and … - Guide Supports.csv. Save them together (your Downloads folder is fine). Their names must differ only at the end: if your browser saved … - Guide Supports (1).csv, take the (1) off.

2

Settings → Lesson activities → Import lesson CSV…, and pick the TEKS Alignment file

Pick the TEKS Alignment file, not the Guide Supports file. The app finds the Guide Supports file beside it by itself. Under the activities, Guide supports lists what each level's guide has, one line each with a count; hover a line that ends in … to see it all. Tick your periods and click Import (or Replace "…" for a lesson you already had: its ticks carry over and no saved day changes).

3

Optional: Settings → Leveled guide supports → Supports to suggest

Nothing here has to be set up: the app reads key phrases in each accommodation ("chunks", "reduced length of assignments", "sentence stems") to know which support covers it. Untick a support to stop its suggestions, or tick one of the four (optional) ones if your guides use it (for example fill-in-the-blank notes), then Save supports.

4

Optional: fix a wording the app matches wrong

Only if you see a wrong dot, or a dot you expected is missing. Open Wordings the app matched (or with no match), change that wording's support or mark (No stops it), and click Save. The row says your change; Use built-in match puts it back.

Part 2

Log a guide day

Why: tap the guide level you handed each student, and the accommodations that guide covers get a gold dot, so the ones you delivered through the guide don't get missed. Column D of the service log notes which level they had.
5

Pick the activity with Lesson activity…

Every present student's card gets a Guide given today row for that lesson: None · L1 · L2 · L3 · L2 LP, with nothing selected. Two activities from the same lesson share one row. Absent and coded students get no row.

6

Tap the level you handed each student

The chips that level's guide covers get a gold dot ● (built in) or a gold ? (might be: look before you click). A line under the chips names the guide.

7

Click the chips you delivered, then Save

A dot never marks a chip. Click each one you delivered, exactly as always, then click Save. Changing only a level makes the button read Unsaved changes. Saved before tapping a level? The row stays: tap it and Save again. Nothing carries to the next day: every row starts blank.

8

Column D shows the level

In the service log, that day's Accom / Mods ends with the level: … Verbal and visual directions (Lvl 1). With no chip marked it reads (Lvl 1) by itself, so the log still shows a guide was given.

✓ You'll know it worked

  • The preview lists Guide supports by level before you import.
  • The line after importing ends Guide supports: 22 saved.
  • Dots appear as soon as you tap a level.
  • Column D ends with (Lvl 1), (Lvl 3, Lvl 2) for two lessons, or (Lvl 2 LP) for large print.

✕ Avoid these

  • Picking the Guide Supports file in Import. Pick the TEKS Alignment file; the supports come with it.
  • Files in different folders. The app only looks beside the TEKS Alignment file.
  • Trusting the dot. It is a reminder, not a mark. Click the chips you really delivered.
  • Typing the activity. The row only comes from Lesson activity…, from a lesson with its Guide Supports file.
