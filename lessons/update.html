Keep it safe

Update to a new version

⏱ About 5 minutes🔁 Whenever a new version comes outYou need: the new Setup file
Why: a new version adds features and fixes. You install it over the one you have: no uninstalling, and your students, days, goals, settings, and backups all stay exactly where they are. Windows doesn't know this app, so it shows a warning or two on the way. This lesson shows each one and what to click.
1

Close SpEd Log Pro first

Save anything you're in the middle of, then close the app with the ✕ at the top right. Closing it saves a backup if you saved anything since you opened it. For extra peace of mind, make a Desktop copy before you update.

2

Get the new Setup file onto the computer

The file is named like SpEd Log Pro v2 Setup ….exe, ending in the version number. Use only the file whose name starts with Setup. If it's on a flash drive, drag it to the Desktop. If you download it from Google Drive, you may see one or both of these:

Click Download anyway, then Keep. In Edge, Keep may be under the … next to the download, followed by Show more → Keep anyway. Both warnings appear because the file is large and not yet well known, not because anything is wrong with it.

3

Double-click it. If Windows says it protected your PC: More info, then Run anyway

A blue box may appear. It doesn't block the app; it hides the button. Click More info: the box now names the file and says Unknown publisher, and a Run anyway button appears. Click it.

No Run anyway button at all, or a message that your administrator blocked it? Your district has turned off installing apps on that computer. Ask your technology office to install the Setup file for you.
4

Let it install. It asks no questions

A small window shows a green bar for a few seconds. There are no choices to make and no administrator password: it installs for you only, in the same place as before. When it finishes, SpEd Log Pro opens by itself.

5

Check it worked

The version next to the app's name, at the top left, now shows the new number, and your students and saved days are all there. Some versions change how the database is stored: the first time the new version opens, it saves a pre-migrate backup and updates the database by itself. There's nothing to click, and nothing to do afterwards.

Skipping versions is fine. You can go from any older version straight to the newest one; it brings the database up to date in one step.

✓ You'll know it worked

  • The app opens by itself after installing.
  • The version at the top left is the new number.
  • Your students and days are all there.

✕ Avoid these

  • Uninstalling first. There's no need, and it's one more chance for a mistake.
  • Running the other .exe. Use the file whose name starts with Setup.
  • Installing an older version over a newer one. See the box on the right.
