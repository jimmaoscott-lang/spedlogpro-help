Goals

Write a measurable goal

⏱ About 5 minutes to set up, then a few minutes per goal🔁 Before an ARDYou need: a Claude account and the student's PLAAFP
Why: a goal the app can track needs one way of scoring it, a clear count, and a plan for checking it in class. A PLAAFP Goal Writer project reads the PLAAFP, asks you a few quick questions, writes three goal choices, and then gives you the finished goal with everything around it: the TEKS it anchors to, how to measure it without the app, a note for the general education teacher, a data sheet, and a … - Goal Setup.csv file that fills in the goal pop-up. It works for any course and grade.
1

Get the prompt

This set of instructions turns a Claude project into a PLAAFP Goal Writer. There's nothing to fill in.

✍️ PLAAFP Goal Writer prompt
4 pages · any subject · nothing to fill in
Download as text
2

In Claude, make a project and paste the prompt

Go to claude.ai, click Projects, then Create project (it may say New project). Name it PLAAFP Goal Writer. One project covers every course: it reads the course and grade from the PLAAFP. Open Instructions (it may say Set project instructions), paste the whole prompt, and save. Choose Sonnet as the model.

3

Add your courses' TEKS (optional, but better)

Upload the TEKS for the courses you write goals for as project files (the Texas Education Agency's TEKS pages: the course introduction and every knowledge-and-skills statement). Then the codes it gives come from them. Without them it still writes the goal, but labels its codes "Check these codes against the current TEKS before using them in the tracker."

4

Paste the PLAAFP and answer its questions

Start a chat inside the project and paste the PLAAFP (or your notes) with the student's name removed. Add the ARD date and the date the goal takes effect if you have them. It asks only what the PLAAFP doesn't answer, one question at a time, each with lettered choices and one marked (recommended): how progress is counted, how often, what mastery looks like, which two accommodations to name, and who collects the data. Answer with a letter.

⚠ Never paste a student's name, ID, birthday, or anything else that identifies them. The goal comes back with [Student] where the name goes; you add the name in your IEP software. If a name slips in, the project won't repeat it, and will remind you.
5

Pick one of the three goals

It writes three goal choices, each measured a different way (for example one correct-out-of-total, one checklist, one rubric), with a line on when each fits best. Answer A, B, or C, or say what to change. Every goal is scored one way: correct out of total or a checklist, never both.

6

Read the seven parts it gives you

PartWhat it is
1. The GoalThe finished goal, starting In 36 instructional weeks, [Student] will… (tell it if your district uses another format)
2. TEKS AnchorThe year-long strand, and Codes: … in the app's short form
3. Measuring it without the trackerThe data source, how often, who collects it, how to record it
4. SpEd Log Pro setupMastery note, Goal check, TEKS, target, method, percentage, and the Goal Setup CSV
5. Teacher HandoffA short note for the general education teacher
6. Data SheetA table to print, one row per data point
7. Form QuestionsQuestions for a Google Form that matches the data sheet
7

Save the Goal Setup file and import it

Save part 4's file (if it only shows the text in a box, copy it into Notepad and save it ending in .csv). After the ARD, import it from the student's gear. Before you click Save goal, change [Student] in the goal text to the wording you want on the card. If the codes carried the "check these" label, the file leaves TEKS out: check them, then type them into TEKS code(s).

✓ You'll know it worked

  • Questions come one at a time, each with lettered choices.
  • The last answer has all seven parts, and a file named like Linear equations - Goal Setup.csv.

✕ Avoid these

  • Pasting names or student details. The PLAAFP's wording is all it needs.
  • Taking it all on trust. It drafts; you and the ARD committee decide the goal.
  • Chatting outside the project. A chat outside it doesn't have the instructions or your TEKS.
