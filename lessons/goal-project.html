Goals

Goal Setup project: make it, then import

⏱ About 5 minutes to make, 3 per goal to import🔁 Once per course; once per goalYou need: a Claude account and your course's TEKS
Why: a Goal Setup project is a Claude project that already holds your course's TEKS. Paste a goal's wording and it gives back the matching TEKS codes, offers ways to track the goal (a checklist or a trial fraction, with rubric levels if they fit) and lets you pick, writes the checklist items or levels and a Goal check, and makes a … - Goal Setup.csv file that fills in the goal pop-up for you.
Part 1

Make the project (once per course)

1

Get the prompt

This set of instructions turns a Claude project into a Goal Setup project. Your course's TEKS go in once, so after that you only paste a goal.

🎯 Goal Setup prompt
4 pages · any subject · you fill in your course and add your TEKS once
Download as text
Already made a Goal Setup project or a TEKS Finder? Keep the project and its TEKS. In its instructions, replace everything above the line TEKS reference with this prompt, and save. The new prompt asks how to track each goal before it writes the file, and adds a Goal check. It still answers with the codes first.
2

In Claude, make a project for your course

Go to claude.ai, click Projects in the left sidebar, then Create project (it may say New project). Name it for the course, like Goal Setup (English 3). Teach more than one subject? Make one per course, since each has its own TEKS.

3

Paste the prompt into the project's instructions

Inside the project, open Instructions (it may say Set project instructions), paste the whole prompt, and save. Choose Sonnet as the model: choosing methods and writing the file exactly right is where smaller models slip.

4

Fill in your course and add your TEKS, once

Change Course: [type your course here, …] to your course. Then replace the last line, [Paste the complete, current TEKS for your course here …], with your course's TEKS from the Texas Education Agency's TEKS pages (the course introduction and every knowledge-and-skills statement). Or upload them to the project as a file and delete that line. Save. If anything is missing later, the project asks for it before it makes a file.

5

Use it: paste a goal, pick how to track it, save the file

Start a chat inside the project and paste one goal's wording, with the name replaced by "Student", worded the way you want it on the card. The answer starts with the codes, like 28A; 28B, then why each fits, then asks How should this goal be tracked? with 2 to 4 lettered choices, one marked (recommended). Each choice is one scored method, a Trial fraction or a Checklist (never both), with Rubric levels added when the goal names prompting or independence. Under the choices it shows the mastery note, a Goal check (how to check the goal in class), the target (Annual ARD unless the goal gives a date), and how the percentage counts.

Answer with a letter, plus any changes ("B, but make the goal check 3 questions"). Then it writes the file, with a Goal check row the app fills in for you. Save the file (if it only shows the text in a box, copy it into Notepad and save it ending in .csv). Then import it (Part 2) from the student's gear.

On a version before 0.4.20? There's no import yet: copy the first line of codes into TEKS code(s) when you set up goal tracking.
⚠ Never paste a student's name, ID, birthday, or anything else that identifies them. Copy only the goal's wording, and replace the name with "Student" first. If a name slips in, the project won't repeat it or put it in the file, and will remind you.
Part 2

Import a goal setup (once per goal)

Why: Importing the project's file fills in the goal pop-up for you, so you check it instead of typing it. Nothing is saved until you click Save goal.
6

Click the gear, then Import goal setup…

On the student's card, click the gear. In the pop-up, click Import goal setup… and choose the file your project made. The gear on that student's card tells the app whose goal it is, so the file never needs a name.

7

Check the filled-in pop-up, then Save goal

Set up goal tracking opens with the file's goal text, mastery note, Goal check, TEKS, and tracking methods. A grey line at the top says which file filled it. The file never sets Effective or Next ARD, so set those, and Target if the file didn't. Change anything you like, then Save goal, the same as if you'd typed it.

The file's goal text becomes the card's IEP Goal wording when you save. Paste the goal into your project worded the way you want it on the card.
8

Already tracking a goal? It's a revision

If the student already has a tracked goal, Revise goal opens instead, with a second grey line naming what the file changes, like Changed from the current goal: Goal text, TEKS, Checklist items. The old goal's progress stays. When the file's goal text differs from the current goal's, This is a new goal (start a new count) at the bottom starts ticked: leave it ticked for a new goal, or untick it if the file only corrects the wording. See Goal progress, step 7.

9

If the file has a problem

Nothing is filled in. The gear pop-up lists every problem by line number, like a second goal in one file, a name line, a method with no items, or a TEKS code it can't read. Ask your project for a corrected file (or fix it in Notepad), click Back, and import again.

10

Both Checklist and Trial fraction on? Turn one off

A goal is scored one way, never both. A file that turns on both still fills the pop-up, with a yellow line, and Save goal is refused until you click one of the two off. The project prompt on this site never writes both; an older file might.

✓ You'll know it worked

  • The answer's first line is only codes, like 28A; 28B.
  • It asks how to track the goal before it makes a file.
  • You get a file named like Inference questions - Goal Setup.csv.
  • The pop-up opens filled in, with Filled from … at the top.
  • After Save goal, a green IEP Goal and Tracking since ….

✕ Avoid these

  • Pasting names or student details. The goal's wording is all it needs.
  • Taking it all on trust. Check the codes and methods before you save the goal.
  • Chatting outside the project. A chat outside it doesn't have your TEKS.
  • Saving without checking. The project suggests; you decide.
  • Importing on the wrong card. The gear you click decides whose goal it is.
  • Pasting names into the project. The goal's wording is all it needs.
