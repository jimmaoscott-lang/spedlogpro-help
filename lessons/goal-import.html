Import a goal setup

⏱ About 3 minutes🔁 Once per goal, and after an ARDYou need: a Goal Setup file from your Goal Setup project
Why: your Goal Setup project reads the goal and picks the TEKS, the tracking methods, and the checklist items or rubric levels. Importing its file fills in the goal pop-up for you, so you check it instead of typing it. Nothing is saved until you click Save goal.
1

Click the gear, then Import goal setup…

On the student's card, click the gear. In the pop-up, click Import goal setup… and choose the file your project made. The gear on that student's card tells the app whose goal it is, so the file never needs a name.

2

Check the filled-in pop-up, then Save goal

Set up goal tracking opens with the file's goal text, mastery note, TEKS, and tracking methods. A grey line at the top says which file filled it. The file never sets Effective or Next ARD, so set those, and Target if the file didn't. Change anything you like, then Save goal, the same as if you'd typed it.

The file's goal text becomes the card's IEP Goal wording when you save. Paste the goal into your project worded the way you want it on the card.
3

Already tracking a goal? It's a revision

If the student already has a tracked goal, Revise goal opens instead, with a second grey line naming what the file changes, like Changed from the current goal: Goal text, TEKS, Checklist items. The old goal's progress stays. Once the wording changes, the progress log starts a new count: see Record goal progress, step 5.

4

If the file has a problem

Nothing is filled in. The gear pop-up lists every problem by line number, like a second goal in one file, a name line, a method with no items, or a TEKS code it can't read. Ask your project for a corrected file (or fix it in Notepad), click Back, and import again.

✓ You'll know it worked

  • The pop-up opens filled in, with Filled from … at the top.
  • After Save goal, a green IEP Goal and Tracking since ….

✕ Avoid these

  • Saving without checking. The project suggests; you decide.
  • Importing on the wrong card. The gear you click decides whose goal it is.
  • Pasting names into the project. The goal's wording is all it needs.
