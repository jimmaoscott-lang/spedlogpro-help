Your roster: make it, download it, drop it in

⏱ About 10 minutes the first time🔁 2 minutes each updateYou need: Google Sheets
Stop 4 of 6
Why: the app looks up each student's minutes, accommodations, and goal in your roster when you add them. Your roster is a Google Sheet you keep; the app reads a downloaded copy of it from one folder on your computer. It only ever reads it: it never changes your Sheet or adds anyone by itself.
Part 1

Make the roster Sheet (once)

1

Type these 8 headings in row 1, in this order

Open a new Google Sheet and name it Roster. In row 1, type these headings across columns A to H, exactly as written and in this order. Keeping this order means Paste from Sheets works later, too:

3

Fill in one row per student

Put all of a student's accommodations in one cell, separated by semicolons: Extended time on assignments and tests; Small group testing. Minutes are a whole number. Dates can be typed 3/20/2027. A student in two of your classes gets two rows (a lesson on that is coming soon).

Part 2

Download it and drop it in (every time you change the Sheet)

4

Download the Sheet as a CSV

File → Download → Comma Separated Values (.csv). It lands in your Downloads folder, named like Roster - Sheet1.csv.

5

Drag it into the Roster folder, and take the old one out

Open File Explorer (⊞ Win + E). Drag the new file from Downloads into C:\SpEd Log Pro Roster. If Windows asks whether to replace the file with the same name, choose Replace. If an older CSV with a different name is there, delete it: the folder must hold exactly one.

6

Check it in the app

In SpEd Log Pro: Settings → Roster → Read roster. Each field should show one of your headings beside it, and the count should match your number of students.

✓ You'll know it worked

  • Read roster says Read "Roster - Sheet1.csv": 15 student rows.
  • On a period tab, clicking District ID or name lists your students.

✕ Avoid these

  • Two CSVs in the folder. Delete the old one every time.
  • Moving or adding columns. Keep the 8 in this order. If you ever change them, download the CSV again before you paste a student.
  • Typing IDs before step 2. The leading zeros are already gone; retype them.
  • Accommodations in separate cells. One cell, semicolons.

⚠ If you see this

No CSV file found in C:\SpEd Log Pro Roster\.The file is still in Downloads: do step 5. More than one CSV file is in C:\SpEd Log Pro Roster\: … Keep only one there.Delete the old file. The roster is missing a required column: …A heading is misspelled: fix row 1 and download again.
